02 · Candidate review and reduction

Success means at least one relevant document in Top-k. Priority uses rank differences, not raw scores across models. Accept only if the rewrite preserves relevance labels. Review new reduced text separately. Regression tests should fail until the known issue is repaired.

Start here for your first experiment

  1. Explore the workflow.Load the demo without downloading models. It demonstrates the interface only.
  2. Run real models.Load the real-model example directly. First use downloads weights; subsequent visits use the browser cache.
  3. Import your dataset.JSON includes documents, queries, relevant document IDs and optional edit rules. Validate before searching.
  4. Review candidates.Expand rankings, inspect labels and meaning, then write a rationale and accept, reject or mark uncertain.
  5. Reduce and recheck.Accept a disagreement before reducing edits. Review any new reduced text again.
  6. Export and run.Real-model cases export a ZIP with a Node.js regression test and instructions. Demo cases export JSON. Known failures should fail until repaired.
