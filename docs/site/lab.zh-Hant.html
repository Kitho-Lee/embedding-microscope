02 · 候選審覈與縮減

成功：Top-k 至少一個相關文檔。優先級使用排名差異；不跨模型比較原始分數。接受意味着你確認變體與原查詢標籤相容；新縮減文本需要另行審覈。迴歸測試在修復前應失敗。

第一次使用，從這裏開始

  1. 體驗流程。選擇演示數據，無需下載模型；它僅用於體驗界面。
  2. 運行真實模型。載入真實模型示例即可運行。首次下載模型，之後瀏覽器會快取權重。
  3. 導入自己的數據。JSON 包含文檔、查詢、相關文檔 ID 和可選替換規則。校驗後再搜索。
  4. 審覈候選。展開排名表，檢查標籤和變體含義，填寫依據後接受、拒絕或標記不確定。
  5. 縮減並複覈。接受模型分歧案例後縮減編輯；新的縮減文本需要重新審覈。
  6. 導出並運行。真實模型案例匯出 ZIP，內含 Node.js 回歸測試與說明。演示案例匯出 JSON。已知失敗在修復前應報錯。

綠色表示 Top-k 命中相關文檔，紅色表示未命中。排名圖越靠上越好。Ctrl / ⌘ + Enter 可運行搜索。
