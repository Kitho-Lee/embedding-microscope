02 · 候选审核与缩减

成功：Top-k 至少一个相关文档。优先级使用排名差异；不跨模型比较原始分数。接受意味着你确认变体与原查询标签相容；新缩减文本需要另行审核。回归测试在修复前应失败。

搜索后展示基线分歧、扰动引发的单模型失败或共同回退。

QUICK START

第一次使用，从这里开始

  1. 体验流程。选择演示数据，无需下载模型；它仅用于体验界面。
  2. 运行真实模型。安装模型依赖后，载入真实模型示例。首次运行需要联网下载权重。
  3. 导入自己的数据。JSON 包含文档、查询、相关文档 ID 和可选替换规则。校验后再搜索。
  4. 审核候选。展开排名表，检查标签和变体含义，填写依据后接受、拒绝或标记不确定。
  5. 缩减并复核。接受模型分歧案例后缩减编辑；新的缩减文本需要重新审核。
  6. 导出并运行。将 ZIP 解压，在已安装项目的环境中运行 pytest test_regression.py。已知失败在修复前应当报错。
